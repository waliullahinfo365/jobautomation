# LinkedIn Apply Assistant (Chrome Extension)

Desktop helper for NewJob Guru — adds a floating **Open in NewJob Guru** button on LinkedIn job pages.

## Install (developer mode)

1. Open Chrome → `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this folder: `extensions/linkedin-apply-assistant`
4. Set your app URL in the extension popup (default: `https://www.newjob.guru`)

## Note

Full Easy Apply automation runs via the **Desktop Apply Agent** (`apps/apply-agent`). This extension is a quick launcher + job-page reminder.
